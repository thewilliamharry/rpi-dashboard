<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Flask | Local browser polling and mutation requests cross the trusted-host/origin/header boundary. |
| web process → SQLite | Read-only status and short operator mutations share the persisted runtime store with the worker. |
| worker entrypoint → scheduler | Only explicit process startup may acquire lifecycle ownership and start background jobs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering / Denial of service | `dashboard.app` import lifecycle | high | mitigate | Fresh-process tests block database, scheduler, browser, probe, signal, and network side effects during import. |
| T-01-02 | Tampering / Denial of service | `dashboard.worker.main` | high | mitigate | Main-only startup plus duplicate-call tests ensure one scheduler path and one recovery-gap record. |
| T-01-03 | Spoofing | `/api/scan-status` worker freshness | medium | mitigate | Derive freshness server-side from persisted heartbeat age; do not accept browser-supplied worker state. |
| T-01-04 | Repudiation | monitoring outage recovery | medium | mitigate | Persist a bounded `monitoring_gap` event before clearing the stale condition. |
| T-01-05 | Information disclosure | browser warning copy | low | accept | Warnings expose only freshness and recovery state on the trusted LAN; no internal addresses, exceptions, or secrets are included. |
</threat_model>
