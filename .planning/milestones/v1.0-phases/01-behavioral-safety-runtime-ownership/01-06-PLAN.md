<interfaces>
Queue states:
- Scan: `queued | running | completed | failed | expired`.
- Preview: `queued | running | completed | failed | expired | superseded`.
- Every row carries `requested_ts`, `deadline_ts`, nullable `lease_owner`, nullable `lease_until`, `attempt_count`, terminal timestamps/result/error, and preview `revision`.

Worker owner state:
- Persisted runtime key contains `worker_id`, `acquired_ts`, `heartbeat_ts`, and `lease_until`.
- Scheduler creation requires a successfully acquired lease; heartbeat renewal uses a conditional owner match.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| web mutations → durable queues | Local requests become work the host-networked worker will execute later. |
| worker contender → owner lease | Multiple processes may attempt scheduler ownership after restart. |
| queue claimant → terminal result | A stale or superseded worker result must not mutate current service state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-26 | Spoofing / Tampering | worker owner lease | high | mitigate | Atomic owner ID/expiry acquisition and conditional renewal gate scheduler start and shutdown stale owners. |
| T-01-27 | Tampering / Denial of service | scan/preview claims | high | mitigate | Short write transactions, row leases, conditional completion, and two-connection race tests prevent duplicate execution. |
| T-01-28 | Denial of service | queued work replay | medium | mitigate | Fixed 15/30-minute deadlines, terminal expiry, attempt counts, latest-preview supersession, and bounded recovery. |
| T-01-29 | Tampering | metadata plus preview enqueue | high | mitigate | Existing mutation guards precede one atomic metadata/revision transaction. |
| T-01-30 | Repudiation | recovery/gap events | medium | mitigate | Persist request IDs/states/timestamps/owner attempts and a deduplicated monitoring-gap watermark/event. |
</threat_model>
