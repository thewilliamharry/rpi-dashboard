<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SQLite main database ↔ WAL/SHM | Sidecars can contain committed state newer than the selected backup. |
| live web process → recovery process | A stale worker does not imply the web has stopped writing. |
| backup catalog → restored database | Only a verified catalog entry may replace the source of truth. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-45 | Tampering / Denial of service | WAL/SHM restore lifecycle | high | mitigate | Exclusive maintenance, zero-busy checkpoint, exact sidecar cleanup, fsync boundaries, and retained-WAL regression. |
| T-01-46 | Tampering / Denial of service | concurrent web metadata writer | high | mitigate | Real Flask transaction versus restore regression proves replacement cannot begin until the managed connection closes. |
| T-01-47 | Repudiation / Tampering | restore durability and repeatability | medium | mitigate | Catalog ID result, integrity/fingerprint recheck, repeated-restore equality, and durable marker ordering. |
</threat_model>
