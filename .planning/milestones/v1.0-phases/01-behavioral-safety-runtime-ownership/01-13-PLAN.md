<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| compatibility shim → package runtime | Legacy assembly may inject operations but package code must not import back into the monolith. |
| browser client → metadata mutation API | Untrusted JSON shapes and scalar values cross into string/database operations. |
| environment → process startup | Operator-provided text config is parsed before the Flask and worker entrypoints start. |

## STRIDE Threat Register — OWASP ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-56 | Tampering | Runtime dependency ownership | medium | mitigate | Explicit operation injection plus package-relative AST resolution prevents hidden reverse imports. |
| T-01-57 | Tampering | Thumbnail persistence | medium | mitigate | Repository-owned parameterized transaction and ownership tests keep SQL at the persistence boundary. |
| T-01-58 | Denial of Service | Scalar JSON metadata | medium | mitigate | Shape/type validation occurs before mapping or string operations; table-driven API tests cover every JSON scalar class. |
| T-01-59 | Denial of Service | Malformed integer environment | medium | mitigate | Bounded Settings parsing with subprocess import tests prevents configuration text from crashing startup. |
| T-01-60 | Information Disclosure | API validation errors | low | mitigate | Stable error envelopes omit exception text and internal module details. |
</threat_model>
