<interfaces>
Existing contracts to preserve:
- `route_browser_request(policy, route) -> bool` plans every browser URL before `route.continue_()` and aborts blocked requests.
- `PolicyProxy` is loopback-only, plans every plain request/CONNECT authority, opens only `RequestPlan.selected_address`, preserves original Host/SNI, bounds concurrency with `BoundedSemaphore`, and reports `active_relays`.
- Chromium contexts use `browser_proxy_context(...)`; production registers `route_browser_request` for `**/*` before page creation.
- Trusted-LAN browser previews may use `ignore_https_errors` only from the eligible service plan; webhooks remain strict and outside this proxy.

Safe-method contract introduced by this plan:
- Retrieval methods are exactly `GET` and `HEAD`, compared after uppercasing the parsed method.
- Playwright rejects every other method before URL policy planning or continuation.
- Plain HTTP proxy rejects every other non-CONNECT method with `405 Method Not Allowed` and `Allow: GET, HEAD` before policy planning or origin connection.
- CONNECT remains the browser's HTTPS transport tunnel; the Playwright route gate must reject an unsafe HTTPS request before Chromium starts/uses that tunnel.
</interfaces>
