<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| acquired WorkerLease -> WorkerAuthority | Only the exact durable epoch returned by acquisition may authorize post-acquisition work. |
| callback entry -> later SQLite transaction | Entry-time authority can expire; each write transaction must re-prove it. |
| Worker A -> successor Worker B | Same worker ID with a rotated epoch must be treated as a different owner. |
| worker mutation -> owner-free web mutation | Worker fencing must not block metadata or durable requests intentionally accepted during outage. |
| read/probe/browser work -> SQLite publication | Expensive results are untrusted until the publication transaction validates current authority. |

## STRIDE Threat Register — OWASP ASVS L1, block on high

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-105 | Spoofing / Elevation of Privilege | reconstructed or same-ID stale epoch | high | mitigate | Task 1 constructs one frozen authority from the real lease and tests absent/mismatched/expired/same-ID-rotated epochs. |
| T-01-106 | Tampering | check-to-write race | high | mitigate | Tasks 1-2 assert after BEGIN IMMEDIATE on the same connection for every queue, runtime, service, event, metric, preview, and cleanup transaction. |
| T-01-107 | Tampering / Repudiation | multi-transaction discovery/uptime/recovery path | high | mitigate | Task 2 exposes deterministic takeover substages for every independent commit and requires zero A delta plus B success. |
| T-01-108 | Denial of Service | web path accidentally owner-gated | medium | mitigate | Tasks 1-2 define named owner-free variants and exercise metadata, scan/preview enqueue, rate-limit, and event controls with no owner row. |
| T-01-109 | Information Disclosure | opaque epoch in logs/errors/API | low | accept | Authority repr and assertion errors are redacted; tests prove tokens do not appear in logs, events, JSON, or exception strings. |
| T-01-SC | Tampering | package supply chain | low | accept | No dependency installation or lockfile change is included. |

All high-severity threats are mitigated by real-SQLite database-matrix evidence; any failing high-severity row blocks the Plan 01-23 handoff.
</threat_model>
