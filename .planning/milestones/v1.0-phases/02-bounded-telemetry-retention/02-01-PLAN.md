<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser request -> Flask route | Untrusted selector and time-range strings enter the historical API. |
| Flask route -> SQLite repository | Validated selectors choose a fixed query shape; all values remain bound parameters. |
| SQLite reader -> response | Reads must finish and close promptly so WAL checkpoints are not pinned. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Denial of Service | `api_telemetry_history` range read | high | mitigate | Reject spans over 90 days, select a server resolution before querying, read at most 2,049 rows, serialize at most 2,048 points, and close the SQLite connection before JSON work. |
| T-02-02 | Tampering | host metric selector in `repositories.py` | high | mitigate | Map four accepted selector values to fixed SQL fragments and bind start/end/limit values; invalid combinations return 400. |
| T-02-03 | Information Disclosure | error responses | low | accept | Return narrow validation messages without SQL, paths, query plans, or database contents; trusted-LAN operational values are intended output. |

## ASVS Level 1 Mapping

| ASVS Category | Applicability | Plan-specific control |
|---------------|---------------|-----------------------|
| V4 Access Control | Applicable as preservation | Register the new history route inside the existing Flask application so Phase 1 Host/Origin request protections still run; keep it read-only and add no mutation or privilege-bypassing path. |
| V5 Validation, Sanitization and Encoding | Applicable | Accept only exact decimal time values and the fixed host metric allowlist, enforce ordered/future/90-day/point bounds before repository access, and bind every range/limit value in the fixed SQL shape. |
| V2 Authentication | Not applicable | Beacon has no accounts or authentication flow in this trusted-LAN milestone, and this read-only telemetry plan introduces none. |
| V3 Session Management | Not applicable | The route creates no login state, cookie, token, or server session. |
| V6 Stored Cryptography | Not applicable | The plan stores local operational telemetry and introduces no secret, credential, encryption key, or cryptographic protocol. |
</threat_model>
