<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| browser -> Flask | A trusted-LAN browser requests a new document, script, and current-diagnosis JSON surface; request Host and method remain untrusted inputs. |
| Flask -> SQLite | The web process may read current evidence but must never acquire worker authority or trigger monitoring work. |
| SQLite values -> browser DOM | Durable labels/timestamps/hostname cross into the page and must be rendered as text without inventing health. |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01 | Tampering | `/api/advanced/current` and advanced controller | high | mitigate | Register GET-only document/static/snapshot routes, accept no selector or mutation body, and source-test that advanced JavaScript performs no mutation request. |
| T-03-02 | Elevation of Privilege | web diagnosis service | high | mitigate | Keep the service Flask-free and effect-free, use only `read_transaction` plus repository reads, and test that no worker/scheduler/probe/preview symbol is reached. |
| T-03-03 | Denial of Service | current host snapshot | medium | mitigate | Use one primary-key row read, close the transaction before serialization, and exclude history, thumbnails, network I/O, and client fan-out. |
| T-03-04 | Spoofing | freshness and refresh status | medium | mitigate | Classify freshness on the server from timestamp/cadence evidence and retain the last successful screen/time on fetch failure instead of claiming a new update. |
| T-03-05 | Information Disclosure | host evidence rendered in DOM | low | accept | The trusted-LAN product intentionally displays local host metrics/hostname; textContent rendering and existing CSP prevent that evidence becoming executable markup. |
