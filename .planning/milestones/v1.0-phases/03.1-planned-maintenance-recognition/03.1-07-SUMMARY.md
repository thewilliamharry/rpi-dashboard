## Decisions Made

## Issues Encountered

- The `attributed_downtime_seconds` boundary-discovery loop (`_covering_boundaries`) needed a bounded anchor-stepping design rather than a single `_local_occurrence_epochs` call, since that helper's own lookback window (`MAINTENANCE_OCCURRENCE_LOOKBACK_DAYS = 2`) is too narrow to guarantee finding every window occurrence across an offline interval spanning more than two days. Resolved by stepping the search anchor backward in lookback-sized strides, capped at `_ATTRIBUTION_MAX_ANCHOR_STEPS` (64) so a pathologically long interval cannot make the search unbounded, while comfortably covering any interval this codebase's retention windows can actually produce. Caught before it became a bug, not after -- no test failure, just design-time reasoning while implementing Task 1.
