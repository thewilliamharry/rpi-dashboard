- Both Task 1 close proofs share one fixture setup (fresh, un-migrated `initial-2026-04.db`) rather than separate bespoke fixtures per test, since that single starting shape forces both the apply loop and the backup branch in one run — proven safe by the pre-existing `test_each_supported_fixture_upgrades_once_preserving_representative_rows` regression, which already exercises the same fixture successfully.
