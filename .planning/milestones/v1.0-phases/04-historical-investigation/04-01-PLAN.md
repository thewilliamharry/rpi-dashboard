- `HISTORY_PRESETS` — an object mapping each preset id to its span in seconds:

  anything else returns the documented default. Persist it from `savePreferences` alongside
  the existing keys. Do not change `PREFS_KEY` — this extends the existing versioned key.
- `resolveRangeBounds()` returns `{start_ts, end_ts}` where `end_ts = Math.floor(Date.now()/1000)`
  and `start_ts = end_ts - HISTORY_PRESETS[state.preferences.historyRange.preset]`. Both are
  integers; they are the only values ever interpolated into a history request URL.
- `fetchRuntimeConfig()` does one `fetch('/api/config')` at init and stores the returned
  `timezone` string on `state.timezone`, falling back to `'UTC'` when the value is absent or
  not a string.
- `formatLocalTimestamp(ts, options)` builds an `Intl.DateTimeFormat(undefined, {timeZone:
  state.timezone, ...options})` and formats `new Date(ts * 1000)`. Every timestamp the History
  surface renders goes through this function. The existing `displayTimestamp` helper at
  advanced.js:87 renders in the *browser's* zone and is the wrong contract for D-05 — leave it
  untouched for the Phase 3 surfaces that already use it, and never route History output
  through it.
- `fetchHostMetricHistory(metric, startTs, endTs)` fetches
  `/api/telemetry/history?kind=host&metric={metric}&start_ts={startTs}&end_ts={endTs}` with
  `{cache: 'no-store'}`, extracting a server-supplied `error` string on a non-ok response and
  throwing it, exactly like the existing `apiFetch`. It returns the parsed body:
  `{requested, selector, effective_resolution_seconds, point_budget,
  source_resolutions_seconds, points, coverage, aggregation_pending}`.
- `buildSeriesPath(points, coverage, scale)` builds the SVG `d` attribute with the
  gap-breaking rule that is the non-negotiable core of D-06. A connecting `L` command is
  emitted from `points[i-1]` to `points[i]` ONLY when the half-open interval
  `[points[i-1].ts, points[i].ts)` is entirely covered by coverage entries whose `state` is
  exactly `observed`; otherwise emit `M` and restart the pen. Gating is on the `observed`
  state alone — `expired`, `not_yet_monitored`, `unknown` and `collection_gap` are all equally
  "do not connect here". The host point fields are `ts`, `min_value`, `max_value`, `avg_value`,
  `latest_value`, `sample_count`, `observed_seconds`, `gap_seconds`, `unknown_seconds`
  (verified in `_compose_host_bucket`); plot `avg_value` as the series value and skip any
  point whose `avg_value` is null. Note the field is `ts`, not `bucket_start` — the composer
  renames it.
- `coverageStripSegments(coverage)` maps each non-`observed` interval to
  `{start_ts, end_ts, pattern, label}` using `COVERAGE_STRIP_VOCABULARY`, which branches on
  `state` and `detail` together, never `state` alone:
  `collection_gap` + `detail === 'storage_pressure'` → pattern `diagonal-hatch`, label
  `Storage pressure (no persistence)`; `collection_gap` with no detail → `dots`,
  `Collection gap`; `unknown` → `dashed`, `Unknown`; `expired` → `diagonal-thin`,
  `Expired (outside retention)`; `not_yet_monitored` → `solid-muted`, `Not yet monitored`;
  `observed` → no segment. Every segment renders at least 3px wide (UI-SPEC Coverage Strip
  Mechanics) and carries its label as a `title` child for non-pointer disclosure.
- `renderHistoryChart(metric, result)` and `renderCoverageStrip(metric, coverage)` write into
  the `chart-{metric}` and `strip-{metric}` SVG elements. `renderSharedTimeAxis(startTs, endTs)`
  writes ticks into `history-time-axis`, each tick label produced by `formatLocalTimestamp`.
- `selectRangePreset(preset)` validates against `HISTORY_PRESETS`, updates
  `state.preferences.historyRange`, calls `savePreferences()`, sets `aria-pressed` on exactly
  one preset button, writes the server-reported `effective_resolution_seconds` into
  `range-resolution-note` (so every preset change is a visible, explainable resolution change
  per D-02), and re-runs `renderHistorySection()`.
- `renderHistorySection()` resolves bounds, fetches CPU, and renders chart + strip + axis.
  Wire the six preset buttons and a `selectSection` hook so entering the History section
  triggers one render. Reuse the existing `state.requestGeneration` staleness-guard idiom so a
  late response from a superseded range can never overwrite a newer render.
