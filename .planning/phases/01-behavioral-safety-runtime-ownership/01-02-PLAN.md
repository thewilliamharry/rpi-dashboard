<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `beacon.web` | Untrusted Host, Origin, headers, URL fields, and JSON metadata enter Flask adapters. |
| `beacon.web` → repositories | Validated operator mutations become parameterized SQLite writes. |
| configuration environment → Settings | Deployment-controlled strings determine database and network policy inputs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-06 | Spoofing / Tampering | Flask mutation hooks | high | mitigate | Preserve trusted Host, same-origin, and `X-Beacon-UI: 1` checks before every mutation adapter. |
| T-01-07 | Tampering | metadata transaction | high | mitigate | Validate allowlisted fields and commit metadata plus preview enqueue atomically with rollback on error. |
| T-01-08 | Tampering / Denial of service | SQLite repositories | medium | mitigate | Parameterized SQL, short transactions, busy timeout, explicit closure, and real-SQLite concurrency-oriented tests. |
| T-01-09 | Elevation of privilege | module dependency direction | medium | mitigate | AST/import tests prohibit domain modules from importing composition roots or Flask request globals. |
| T-01-10 | Information disclosure | route errors | medium | mitigate | Map expected validation/storage failures to established safe JSON messages without raw SQL, paths, or exceptions. |
</threat_model>
