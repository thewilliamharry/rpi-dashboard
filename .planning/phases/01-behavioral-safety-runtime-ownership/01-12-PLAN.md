<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| configured URL/DNS → outbound socket | Untrusted names and mutable DNS answers select LAN or internet destinations. |
| Chromium → proxy → origin | Browser-controlled redirects and subresources cross the same outbound boundary as the main frame. |
| TLS authority → numeric connection | Connection routing and certificate identity intentionally use different values. |

## STRIDE Threat Register — OWASP ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-51 | Spoofing | DNS rebinding between policy and socket | high | mitigate | Open sockets only to the numeric address contained in the validated plan and prove the destination with real-origin tests; high-severity tests block completion. |
| T-01-52 | Elevation of Privilege | Chromium redirects and subresources | high | mitigate | Force all browser connections through a loopback-only policy proxy that re-resolves and validates every authority before connecting. |
| T-01-53 | Spoofing | HTTPS identity | high | mitigate | Preserve original SNI and certificate hostname while pinning only the socket destination; deterministic TLS SNI/certificate tests block completion. |
| T-01-54 | Denial of Service | Browser relay | medium | mitigate | Bound concurrent tunnels, headers, idle time, response sizes where visible, and cleanup on both normal and error paths. |
| T-01-55 | Information Disclosure | Transport errors | medium | mitigate | Return stable safe error categories and keep destination details in sanitized logs only. |
</threat_model>
