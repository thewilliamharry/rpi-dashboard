- `PUT /api/service-meta/<port>` accepts a JSON object, rejects unknown/string-field type errors with JSON 400, validates the effective URL through `OutboundPolicy`, and commits metadata plus the latest preview request in one SQLite transaction.

Field contract introduced by this plan:
- Present `critical`: `type(value) is bool`.
- Present `pinned_order`: `type(value) is int` and `0 <= value <= 65535`; JSON booleans are rejected even though Python treats `bool` as an `int` subclass.
- Omitted values are not revalidated or rewritten; current persisted values pass through unchanged.
