<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| production composition -> static test registry | A callback or effect omitted from the registry would create false closure evidence. |
| Worker A -> SQLite durable owner -> Worker B | Real persisted epoch takeover must not be replaced by a process-local or mocked authority. |
| read/probe completion -> mutation/effect boundary | Results collected while A was current become untrusted after B acquires. |
| test collaborator -> production path | Deterministic doubles may replace expensive inputs, but must not bypass the real transaction/delivery integration. |

## STRIDE Threat Register — OWASP ASVS L1, block on high

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-101 | Tampering / Elevation of Privilege | omitted production callback or effect | high | mitigate | Task 1 inventories `WorkerOperations`, startup, scheduler, lifecycle, database surfaces, and effect classes and emits concrete missing/excess failures. |
| T-01-102 | Tampering / Repudiation | mocked or incomplete takeover evidence | high | mitigate | Task 2 uses real SQLite owner acquisition, deterministic A/B timing, declared full-surface snapshots, and one B control per row. |
| T-01-103 | Denial of Service | disabled work masquerades as stale-worker safety | medium | mitigate | Every case requires current B to complete the same production operation and expected effect. |
| T-01-104 | Information Disclosure | opaque owner epoch in assertion output | low | accept | Test failure labels use stable row IDs and redacted identity roles; token values are never part of messages or serialized fixtures. |
| T-01-SC | Tampering | package supply chain | low | accept | No package is installed and no dependency/lock file changes; existing Python, SQLite, and pytest facilities are used. |

All high-severity threats are mitigated by executable Tasks 1-2; Plan 01-21 cannot be considered complete if either exhaustive-inventory or real-SQLite evidence is absent.
