<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser query -> selector/range parser | All request strings are untrusted even on the trusted LAN. |
| validated request -> tier repositories | Only fixed query shapes may cross into SQLite and every value remains parameterized. |
| SQLite WAL reader -> response composer | Query duration and materialized rows must remain bounded so interactive reads cannot grow/pin the WAL. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-18 | Denial of Service | mixed-tier historical query | high | mitigate | Validate max 90-day span, select resolution first, group each source in SQLite, cap at budget+1, assert 2,048 output, and close before serialization. |
| T-02-19 | Tampering | kind/metric/service selectors | high | mitigate | Accept exact selector combinations, map them to fixed SQL shapes, range-check ports, and bind every time/bucket/port/limit value. |
| T-02-20 | Information Disclosure | validation/query errors | medium | mitigate | Return fixed 400 messages with no SQL, filesystem path, worker epoch, or database diagnostic detail. |
| T-02-21 | Spoofing | coverage state | medium | mitigate | Derive a complete partition from persisted stream/coverage/job evidence and reject gaps/overlaps instead of labeling complement optimistically. |
</threat_model>
