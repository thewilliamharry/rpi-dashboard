<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| snapshot JSON -> advanced renderers | Durable and derived strings/counts may be missing or long; renderers must preserve semantics and never execute content. |
| localStorage -> route-local state | Browser-local preference JSON is untrusted/malformed and must not become monitoring input or live evidence. |
| browser timer -> current GET API | High-frequency polling can load the Pi or create misleading refresh state if multiple timers or failure transitions are mishandled. |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-12 | Tampering | advanced presentation controls | high | mitigate | Keep every control local, source-test that the sole data call is GET `/api/advanced/current`, and provide no operation/action endpoint or fetch. |
| T-03-13 | Spoofing | refresh/last-success/error UI | high | mitigate | Advance timestamps only after success, retain old evidence on failure, distinguish connection/worker/recovery, and test exact failure/pause transitions. |
| T-03-14 | Denial of Service | auto-refresh timer | medium | mitigate | Allow only 5/15/30/60 seconds, default 15, own one timer, pause cleanly, and retain the backend's one bounded request per tick. |
| T-03-15 | Information Disclosure | browser persistence | medium | mitigate | Allowlist only presentation preferences; do not persist snapshots, errors, service evidence, warning selections, expanded rows, or server effective settings. |
| T-03-16 | Spoofing | typed pipeline states | medium | mitigate | Render server labels and evidence separately with text/non-colour markers; never recompute or collapse freshness, gaps, pending, pressure, expiry, or TLS. |
