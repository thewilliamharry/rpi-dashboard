<objective>
Close the blocking half of the Services fabrication gap: stop the advanced workspace from inventing a measurement the server never supplied. Reject absent before coercing to zero at all three sites that currently coerce, and prove the corrected behaviour in a real browser through the production `/advanced` route.

Purpose: `Number(null) === 0` passes `Number.isFinite`, so every offline and every unknown service -- precisely the rows an operator opens this workspace to diagnose -- reports a latency of `0 ms` beside a red offline marker, and the latency sort ranks those fabricated zeros as the fastest things on the Pi. The failure class the server did supply, and which `03-UI-SPEC.md:118` explicitly contracts for that cell, is unreachable from any real payload. The same coercion renders an unestablished state duration as `0 seconds`. This is the identical defect class the phase has already failed for once on the collection-health surface.
Output: A services table whose every rendered measurement is derivable from a value the server actually sent, and browser regressions that lock that in.

Tracer note: this is a gap-closure round against a fully wired system, so there is no architecture left to prove. Tracer-first is honoured in shape rather than skipped: Task 1 is the thinnest complete vertical slice -- one absent value, through the shared rule, through the renderer, to one asserted DOM cell in a real browser on the production route. Task 2 expands horizontally from that proven slice to the sort key and the duration reader, which reuse the same rule.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server JSON payload -> operator-facing DOM | An absent value crossing this boundary must arrive as an explicit absence, never as a number the operator can act on. |
