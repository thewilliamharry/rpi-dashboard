<objective>
Stop the worker from recording a success as a failure. Decide what a background callback actually did before, and outside, the scope that records it, and let a failure of the recording surface as its own named condition rather than as a verdict on the work.

Purpose: `dispatch_callback` performs the durable `succeeded` write inside the same `try` as the work, so a transient SQLite error on that write is caught by the generic `except Exception` and durably recorded as `state='failed'` for a callback that succeeded. The verifier reproduced it: with the work returning True and the `succeeded` write raising `OperationalError`, the written sequence was started, succeeded, failed. `compose_active_exceptions` then promotes that row as a `job_failed` exception on the Overview safety surface -- so the one place an operator looks to learn whether background collection is healthy tells them a healthy job is broken.
Output: A dispatch path where the durable record of what a job did is decided by what the job did, and a regression that holds it there.

Tracer note: this is gap closure against an already-wired subsystem, so there is no architecture to prove. Tracer-first is honoured in shape: Task 1 is one complete vertical slice -- an injected bookkeeping fault, through the restructured dispatch, to the durable row, to the composed operator-facing exception list -- and Task 2 expands to the adjacent outcome paths that must be proven unchanged.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| callback work -> durable `background_job_health` row | What a job did must cross into the durable record unchanged by whatever happened to the write itself. |
| durable job row -> Overview exception card | Any row in the failed state is promoted to the operator's primary safety surface, so a false row becomes a false alarm at the point of greatest trust. |
| underlying exception -> durable evidence and raised condition | Messages, paths and SQL fragments must not cross this boundary; only a bounded class name may. |
| worker epoch authority -> SQLite write | Only the current lease holder may publish durable job health; a restructure must not weaken that fence. |
