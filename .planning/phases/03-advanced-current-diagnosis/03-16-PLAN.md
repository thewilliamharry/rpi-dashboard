<objective>
Stop an unmonitored service from reading as a clean bill of health.

Purpose: 03-13's server work derives four distinct completeness states from durable truncation flags, and only a literal boolean false is allowed to yield the absent state. The verifier confirmed all four are correct and reproduced them end-to-end. The client then throws one distinction away: a single branch renders the same string for a service whose stream list is complete and contains no stream for it at all, and for a service that has been fully collected and is genuinely clean. The first means the telemetry pipeline has no record of ever observing that service — reachable in production for a newly discovered service before its first persisted probe, and for any service probed while storage pressure suppresses persistence, where the gap lives in runtime state and creates no stream row. The second means everything is fine. They currently read identically, and 03-13's own browser regression asserts the same literal for both, so the test pins the conflation shut rather than protecting the distinction.

The second half of the plan hardens the rule the whole surface now depends on. `finiteMeasurement` is the single absent-value rule for latency, state duration and gap counts, and it was written against a list of observed values rather than as a rule: a whitespace string, an empty array and a boolean all become the measurement zero. Unreachable from today's server, but this is the one function standing between a server value and exactly the fabricated copy this round exists to remove — and on the gap count, a zero would render a real, non-empty gap list as no gap evidence.

Output: An advanced workspace where an absence of collection reads as an absence of collection, a test that protects that distinction instead of pinning it shut, and an absent-value rule that is a rule.
</objective>
