<objective>
Expand outward to MNT-02: notice, from the outages Beacon already recorded, that a service restarts
at about the same time most nights — and offer the operator a window describing it, without changing
anything until they say so.

The suggestion is deliberately inert. It is computed at read time from `events` rows, returned only
inside the metadata payload the editor already fetches, and never written anywhere the coverage
evaluator can see it. D-12 makes recomputation the mechanism: the operator always sees a proposal
matching what the service has actually been doing lately, and a pattern that stops recurring simply
stops being offered.

Purpose: satisfy MNT-02's detection half — three similar daily restart outages producing an inactive
candidate — with tolerances that are grounded, named, and configurable rather than guessed inline.

Output: the pure detector and its overlap-withholding companion, three configurable settings, the
evidence read, and the suggestion field on the service-meta GET.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Stored `events` rows → detector | Historical rows of unknown quality feed a read-time computation that runs inside a web request. |
| Detector output → operator | The proposal is advisory only and must not be mistaken for configuration. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-23 | Denial of Service | An unbounded evidence scan making the editor's GET slow or unbounded on a long event history | high | mitigate | The repository read is bounded by both the configured lookback and a finite row limit, in the spirit of the existing capped pipeline reads; pinned by `SuggestionEvidenceTests`. |
| T-03.1-24 | Denial of Service | Malformed evidence raising inside a web request handler | medium | mitigate | The detector drops any element it cannot interpret and returns no suggestion rather than raising; pinned by `test_malformed_evidence_yields_no_suggestion_and_does_not_raise`. |
| T-03.1-25 | Tampering | A suggestion silently becoming active configuration | high | mitigate | The detector writes nothing; the suggestion is computed at read time and lives only in the response body; pinned by the whole-database row-count snapshot in `test_no_row_is_written_by_computing_a_suggestion`. |
| T-03.1-26 | Information Disclosure | A suggestion leaking a service's outage history onto a surface it does not belong on | low | mitigate | The suggestion is attached only inside the per-service metadata response; pinned by `test_the_suggestion_appears_on_no_other_endpoint`. |
