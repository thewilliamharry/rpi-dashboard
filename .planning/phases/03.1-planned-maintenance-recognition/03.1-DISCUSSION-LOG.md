**Notes:** The timer causing the restart is itself wall-clock local, so matching it keeps the window aligned. → D-02

## Suppression mechanism

Mechanism itself was not put to a vote — record-and-tag then filter at read is forced by Phase 2 D-03 and D-05. Only the feed's default visibility was open.

| Option | Description | Selected |
|--------|-------------|----------|
| Hidden by default, revealable with count | Real noise reduction; hidden count means a suppressed night never reads as uneventful | ✓ |
| Always shown, styled as expected | Nothing withheld; nightly restart still fills the feed, just quieter | |
| Hidden with no reveal | Cleanest feed; dashboard silently disagrees with the stored record | |

**User's choice:** Hidden by default, revealable → D-10

## Suggestion lifecycle

| Option | Description | Selected |
|--------|-------------|----------|

**Notes:** The discoverability cost was stated before the choice and is recorded as a noted consequence on D-11. A card indicator remains additive and revisitable. → D-11

| Option | Description | Selected |
|--------|-------------|----------|

**User's choice:** Persists, refreshed against recent evidence
**Notes:** Asked as a direct consequence of D-11 — with no surface outside the editor, staleness matters more than it otherwise would. → D-12
