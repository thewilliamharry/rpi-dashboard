## Wave 0 Requirements

**Owner:** every Wave 0 gap below is closed by plan `03.1-01` task 2 (the phase's leading tracer),
except the runtime dependency, which is closed by plan `03.1-02` task 2 after its blocking package
verification.

- [ ] `tests/test_maintenance_windows.py` — new file covering MNT-01 through MNT-04, following the
      existing `unittest.TestCase` + `tests/helpers.py::load_app` pattern.
- [ ] **Clock-freeze fixture reuse** — reuse the `_freeze_clock` pattern proven in
      `tests/test_advanced_diagnosis_api.py:27-45` (`mock.patch('time.time', ...)` installed and
      torn down via `self.addCleanup(patcher.stop)`). That file's own `ClockIsolationTests`
      regression (WR-05) guards against a frozen clock leaking across test modules — this phase
      must not break it.
- [ ] **DST calendar selection** — DST tests need a real IANA zone with known transition dates
      (e.g. `America/New_York`: 2026 spring-forward 2026-03-08, fall-back 2026-11-01). This is a
      *calendar-date* concern that freezing `time.time()` alone does not solve, since `zoneinfo`
      transition rules are keyed by wall-clock date.
- [ ] **Runtime dependency** — add `tzdata` to `dashboard/pyproject.toml`. No test-time special
      handling needed; it behaves identically in test and production.
- [ ] Framework install: none — pytest is already present.

- [x] No `git diff -U0` gate is unanchored. `-U0` prints the enclosing function name in the `@@` hunk header, so an unanchored grep matches the header rather than a changed line; every such gate now anchors on `^[+-]` or `^\+`.
