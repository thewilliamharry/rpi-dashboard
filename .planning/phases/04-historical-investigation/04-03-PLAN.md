Give every drawn thing a way to say exactly what it is.

**Point tooltips (HIS-01).** `renderPointTooltip(metric, point)` populates a single shared
`history-chart-tooltip` element with the point's exact local timestamp (through
`formatLocalTimestamp`, never a browser-zone formatter), its value, and its unit — for example
a temperature point reads as its value followed by `°C` and its local wall-clock time. Show it
on `pointerover` of a point target and on keyboard focus of the chart's point list, hide it on
`pointerout` and blur. Pointer-driven updates are coalesced through `requestAnimationFrame` and
update only the tooltip element's text and transform — chart `<path>` `d` attributes are never
regenerated in response to a pointer event (Research Pitfall 3; this rule is established here so
plan 04-08's cross-chart cursor inherits it rather than reinventing it).

**Merged sub-pixel segments.** `mergeStripSegments(segments, pixelsPerSecond)` merges only
*adjacent segments carrying the same reason* whose rendered widths would fall below the 3px
minimum, and never merges two adjacent segments with different reasons — each keeps its own
minimum-width slot so the exhaustive five-state partition survives on screen at the 90d preset.
`segmentTooltipText(merged)` produces exactly `{Reason} — {N} intervals, {duration} total`, so
a merged segment discloses the true count and total duration it stands for and compression can
neither overstate nor hide how much is actually missing. A single unmerged segment keeps its
plain reason label.

**Point reduction, if any.** The server already bounds every series to at most 2048 points
(`point_budget`), so no client-side decimation is introduced. If a future measurement shows a
2048-point path is the bottleneck, any reduction added must preserve the observed minimum and
maximum of every bucket it collapses — record this constraint as a comment on the render entry
point so the next change cannot quietly trade evidence for frame rate.

**No completeness roll-up.** Do not add any element, label or tooltip that expresses coverage as
a single percentage or score for a chart or for the stack. Missing time is disclosed by reason
and duration, per segment, and nowhere else.
